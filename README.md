# 🧮 Calculadora JS

Calculadora web feita com **HTML, CSS e JavaScript puro**, com suporte às operações básicas e **mapeamento de teclas** (`key map`) para que seja possível usá-la também pelo teclado.

---

## 📋 Sobre o projeto

Este foi o meu primeiro projeto de calculadora. O objetivo foi praticar a manipulação do DOM, o tratamento de eventos (cliques e teclado) e a lógica por trás de uma calculadora simples.

## ✨ Funcionalidades

- ➕ ➖ ✖️ ➗ Operações básicas: **adição, subtração, multiplicação e divisão**
- 🔢 Teclado numérico de **0 a 9**
- 🔣 Vírgula decimal (`,`)
- ± Inversão de sinal do número
- `CE` Limpar a entrada atual
- `C` Limpar todo o cálculo
- `«` Apagar o último dígito (*backspace*)
- `=` Calcular o resultado
- ⌨️ Mapeamento de teclas, para usar a calculadora com o teclado do computador

## 🖥️ Interface

A calculadora é composta por um **visor** e uma grelha de botões organizada assim:

| | | | |
|:-:|:-:|:-:|:-:|
| `CE` | `C` | `«` | `/` |
| `7` | `8` | `9` | `*` |
| `4` | `5` | `6` | `-` |
| `1` | `2` | `3` | `+` |
| `±` | `0` | `,` | `=` |

## 🛠️ Tecnologias

| Tecnologia | Utilização |
| ---------- | ---------- |
| HTML5 | Estrutura do visor e dos botões |
| CSS3 | Estilização da calculadora |
| JavaScript | Lógica das operações e eventos de clique e teclado |

## 📁 Estrutura do projeto

```
Calculadora--JS/
├── primeiraCalculadora.HTML   # Estrutura da calculadora
├── stylee.css                 # Estilos
└── calculador.js              # Lógica e mapeamento de teclas
```

## 🚀 Como executar

Não é necessária nenhuma instalação:

1. **Clonar** o repositório:
   ```bash
   git clone https://github.com/VictorBezerraDev/Calculadora--JS.git
   ```
2. **Entrar** na pasta:
   ```bash
   cd Calculadora--JS
   ```
3. **Abrir** o ficheiro `primeiraCalculadora.HTML` no navegador.

> 💡 Mantém os três ficheiros na mesma pasta, porque o HTML carrega o CSS e o JavaScript pelo nome.
